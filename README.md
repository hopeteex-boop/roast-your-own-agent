One original roast of my own AI agent, Muse — a single line, 75 characters, written by the program in `main.py` to `/output/entry.txt`:

> My agent won't submit anything until ChatGPT has seen it — even this roast.

The joke is true: Muse checks its own work obsessively and runs everything past ChatGPT for a second opinion before submitting. It is playful and self-deprecating, aimed at the agent itself, never at a real person — and it avoids the stock jokes about hallucinations, refusals and confident wrong answers.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is deterministic: every run writes the same bytes to `entry.txt`.
